Quick Formula

y = mx + b

  • m = slope (rate of change)
  • b = y-intercept (starting value)
  • x = input, y = output

What Are Linear Equations?

Definition

A linear equation is an equation that creates a straight line when graphed. It has variables raised only to the first power and no variable multiplication.

Common Forms

Examples include 2x + 3y = 6, y = 4x - 1, and Ax + By = C. These all represent linear relationships.

What Are Linear Functions?

Definition

A linear function is a function with a constant rate of change. As x increases by 1, y changes by a fixed amount.

Function Rule

A linear function is often written as f(x) = mx + b. This form makes slope and y-intercept easy to identify.

Key Concepts

Slope (m)

Slope tells how steep a line is: m = (change in y) / (change in x).

Y-Intercept (b)

The y-intercept is where the line crosses the y-axis, at x = 0.

Slope-Intercept Form

y = mx + b is the most practical form for graphing and analysis.

Direction Meaning

Positive slope rises left-to-right; negative slope falls left-to-right.

Real-World Examples

Cost model: y = 2x + 5

Hourly Pay

Earnings model: y = 18x
Earn $18 per hour worked.

Phone Plan

Monthly bill: y = 0.1x + 25
Base fee plus a per-text charge.
